# EASTCON — главная страница

Статичный сайт без сборки: HTML + CSS + JS. Анимация — GSAP + ScrollTrigger (подключены с cdnjs).

## Структура
```
index.html        разметка всех блоков + выпадающее меню «Продукция»
css/style.css     все стили (адаптив: 1100 / 820 / 650 px)
js/main.js        меню, лента категорий, scroll-анимация первого экрана
assets/img/       изображения (WebP/PNG, уже оптимизированы)
```

## Публикация на GitHub Pages
1. Загрузите содержимое папки в репозиторий (корень репозитория = папка с `index.html`).
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)`.
3. Сайт откроется по адресу `https://<user>.github.io/<repo>/`.

## Настройка анимации (js/main.js)
- `PIN_DESKTOP` / `PIN_MOBILE` — длина перехода первого экрана в экранах (1.8 = 180vh).
- Этапы заданы в долях таймлайна: 0–0.2 надпись гаснет, 0.12–0.65 лазер уменьшается и уезжает вправо, 0.24–0.62 появляются товары, 0.65–1 появляется текст.
- При `prefers-reduced-motion` показывается итоговый второй экран без анимации.

## Важно
- Изображения с пометкой CONCEPT (категории, новости, презентация, часть товаров) — демонстрационные, перед запуском заменить официальными фото. Файлы можно подменять с тем же именем.
- Тексты новостей, адрес и телефон в подвале взяты из макетов и требуют утверждения.

## Страницы
- `index.html` — главная.
- `massage-chairs.html` — страница «Массажные кресла» (`css/product.css`, `js/product.js`). Ссылки на неё ведут из меню «Продукция», карточек категорий и подвала.
